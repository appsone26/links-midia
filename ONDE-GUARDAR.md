# Onde guardar cada mídia

Regra simples para todas as sessões:

| O que é | Onde vai |
|---|---|
| Vídeo com **pessoa real falando** (apresentador feito por IA), do Ezerion | `ezerion/apresentador/` |
| O mesmo, do Cataki | `cataki/apresentador/` |
| O mesmo, dos jogos | `jogos/apresentador/` |
| Cartazes, artes, cards, gibis, Reels animados | continuam nas pastas de cada marca, como hoje |

Cada vídeo fica em uma subpasta com data: `AAAA-MM-DD-nome-do-video/` com `video.mp4`, `capa.jpg` e `legenda.txt`.
Detalhes no `LEIA-ME.md` dentro de cada pasta `apresentador`.

Sempre guardar em `links-midia` (não em `links`). O repositório `links` é só a página de links e promoções do dia.
